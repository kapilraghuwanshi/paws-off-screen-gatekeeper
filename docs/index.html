// why_it_exists

Website blockers feel like homework. This one feels like being interrupted by a tiny supervisor.

PawsOff is intentionally playful: no guilt dashboard, no productivity sermon, no account. Just local settings, target sites, a countdown, and the cutest interruption when scrolling wins.

// how_it_works

Three commands. Zero config files.

01
$ pawsoff add youtube.com

Add target sites

Guard X, YouTube, Reddit, Facebook, Instagram, or any custom website you keep doom-scrolling.

02
$ pawsoff --limit 30 --break 5

Set your timer

Choose how many minutes before the puppy appears, then pick the break duration. That's it.

03
$ pawsoff deploy --puppy 🐶

Respect the takeover

The puppy slides in from the side, blocks the entire page, and keeps watch until your break countdown ends.

// live_preview

// sys_specs

Built lean. Ships clean.

🎯

Custom target sites

Add any URL. Default guards: X, YouTube, Reddit, Facebook, Instagram, TikTok, LinkedIn.

⏱

Adjustable timers

Usage limit: 1–60 min. Break duration: 1–10 min. Fine-tune from the popup or options page.

👁

Smart tracking

Timer only counts when a guarded tab is visible and focused. Switch tabs = timer pauses.

🔒

100% local

All settings stored in Chrome local storage. Zero data leaves your machine. No accounts.

🐕

Real puppy overlay

A photorealistic puppy slides in, sits on the page, and supervises your break with a countdown.

🚫

No ads. Free forever.

No premium tier, no tracking pixels, no analytics. Open source on GitHub.
