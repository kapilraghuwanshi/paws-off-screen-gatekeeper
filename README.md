# 🐶 PawsOff

**The cutest forced break.** A Chrome extension where a real puppy takes over distracting sites when your timer runs out.

> Spend too long on selected sites? A puppy hijacks your screen. No guilt dashboard, no productivity sermon — just a puppy.

## Features

- 🎯 Default guarded sites: X/Twitter, Facebook, Instagram, YouTube, Reddit, TikTok, LinkedIn
- 🌐 Custom sites from the options page or popup
- ⏱ Usage limits: 1, 15, 30, 45, or 60 minutes
- 🐕 Puppy break durations: 1, 2, 5, or 10 minutes
- 👁 Counts time only when a guarded tab is visible and focused
- 🖼 Full-page photorealistic puppy overlay with countdown
- 🔒 Local-only storage — no data is sent anywhere
- 🚫 No ads, no accounts, free forever

## Install from Chrome Web Store

Coming soon! For now, load locally:

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `puppy-gatekeeper-extension` folder
5. Open the popup or options page to configure

## Quick Test

Set the usage limit to **1 minute** for a fast demo. Use the popup "Reset timer" button to clear and retest.
