## What is PawsOff?

PawsOff is a free, open-source Chrome extension that helps you manage your screen time — not with guilt dashboards or productivity lectures, but with something irresistible: **a puppy that walks onto your screen and sits there until your break is over**.

Pick the sites you want to guard (YouTube, Reddit, Twitter, etc.), set how many minutes you're allowed, and browse normally. When your time is up, a real animated puppy slides in, locks the page, and counts down your break. The page unlocks automatically when it's done.

## ✨ Features

- 🐕 **Real animated puppy overlay** — walks in, sits down, and supervises your break
- 🌐 **Per-site blocking** — guard only the sites you choose
- ⏱ **Custom timers** — set usage limit (1–60 min) and break duration (1–10 min)
- 👁 **Smart detection** — only counts time when the tab is active and focused
- 🔒 **100% local** — no data collected, no accounts, no servers
- ⚡ **Lightweight** — pure vanilla JS, no frameworks or trackers
- 🚫 **Free forever** — no ads, no subscriptions

## 🚀 Install

**[→ Add PawsOff to Chrome](https://chromewebstore.google.com/detail/pawsoff/fndochdepjhdgjncaaenejjikecennlk)** — free, one click.

Or **load locally for development**:

```bash
git clone https://github.com/kapilraghuwanshi/paws-off-screen-gatekeeper.git
```

1. Open `chrome://extensions` in Chrome
2. Enable **Developer mode** (toggle, top right)
3. Click **Load unpacked**
4. Select the cloned folder
5. Click the 🐾 icon in your toolbar to open settings

---

## 🎮 Quick Test

1. Open settings → set usage limit to **1 minute**
2. Visit `youtube.com` or `reddit.com`
3. Keep the tab active and focused
4. Watch the puppy arrive 🐶
5. Use **Reset timer** in the popup to test again

## 🔒 Privacy

PawsOff stores your settings (site list, timers) locally on your device using Chrome's `storage.local` API. **No data is ever collected, transmitted, or shared.** There are no analytics, no ads, and no external servers.
